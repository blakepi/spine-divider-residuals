# Release Notes: v1.0.0-submission

Submission release for *Residual Limits of a Load-Normalized Spine-Neck Ratio in Compartmental Models*.

## Scope

- Nature Neuroscience unblinded Article package.
- Public-release staging repository with MIT code license and CC BY 4.0 data/docs license.
- Final QA, claim numeric audit, figure QA, release audit, and portal field guide.
- Bounded validation outputs and source-data provenance.

## Scientific framing

- `SMI = R_neck / R_in,d` is an author-defined compact coordinate.
- `Gamma_div = 1/(1+SMI)` is the classical DC divider expectation.
- `Delta_div = Gamma_h_to_d - Gamma_div` is the residual-domain target.
- The release does not claim NEURON validation, biological prevalence, or high-SMI uncertainty coverage in the N=768 uncertainty ensemble.
