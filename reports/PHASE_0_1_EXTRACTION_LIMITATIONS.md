# Phase 0.1 Extraction Limitations

## Summary

Phase 0.1 supports GO_SUMMARY_ONLY, not GO_PER_SPINE. The limiting issue is not the SPINE model or local tooling; it is the absence of fully machine-recovered per-spine Harnett paired load/neck rows and blocked access to some contrast-source full texts.

## Harnett 2012

The acquired Harnett material provided machine-readable model/proxy values and summary context, but not the native measured paired R_neck/R_d-EPSC dataset. Per-spine extraction from figures was not accepted because Phase 0.1 did not produce a fully scripted axis-calibration, point-detection, count-validation, uncertainty, and QC-overlay workflow.

Implication: Harnett can anchor only a conditional summary/model-proxy high-rho_L point in a later feasibility figure.

## Popovic 2015

Popovic was the strongest machine-readable source in this phase. The PDF text provided measured summary R_neck, same-source Zdendrite, AR, n, and model-fit values. Per-spine scatter rows were not extracted.

Implication: Popovic can anchor a measured summary low-rho_L contrast point, but not a per-spine empirical sample.

## Kwon 2017

Scripted retrieval reached metadata but not a usable full text/PDF or supplement. Numeric values expected by the prompt were not accepted because they were not recovered from a machine-readable primary source in this run.

Implication: Kwon is excluded from numeric Route 1 tables until a machine-readable open source is acquired.

## Cornejo 2022

Scripted retrieval reached metadata but the primary full text/PDF route was blocked. No paired R_neck/load quantity was recovered.

Implication: Cornejo remains contrast-only and must not be plotted in rho_L coordinates.

## Zecevic 2023

The review was machine-readable and useful for divider framing and context. It is not primary empirical data for Route 1.

Implication: Use for limitations and interpretation only.

## Automated Figure Digitization

No automated digitization was accepted. This avoids hidden manual curation and protects the distinction between summary-level feasibility and per-spine empirical analysis.
