# Journal Strategy

## Primary target: Nature Neuroscience

Rationale: the paper addresses a fundamental computational-neuroscience interpretation problem for dendritic spine-neck electrical isolation. The strongest pitch is not a new universal scalar index; it is a residual-domain framework that separates the expected local voltage divider from transient conductance-based behavior.

Candid risk: Nature Neuroscience is high-risk. Desk-rejection risk is substantial because the work is a compact computational/modeling study without new experimental data. The cover letter and abstract should foreground why this changes interpretation for spine electrical isolation broadly.

## Fallback targets

- Nature Methods: strongest if reframed around reproducible computational methodology and validation; would need reduction to up to 6 display items and a methods/tool emphasis. Source: https://www.nature.com/nmeth/content.
- Nature Communications: plausible if framed as broadly relevant computational neuroscience with rigorous reproducibility; original research Article format is flexible but still high-bar. Source: https://www.nature.com/ncomms/submit/article.
- Journal of Computational Neuroscience: strong disciplinary fit for mathematical/computational model papers; likely best technical fallback. Source: https://link.springer.com/journal/10827/submission-guidelines.
- Frontiers in Computational Neuroscience: practical fallback for open-access computational neuroscience, especially Technology & Code or Original Research; DOI-backed code release becomes important. Source: https://www.frontiersin.org/journals/computational-neuroscience/for-authors/article-types.
